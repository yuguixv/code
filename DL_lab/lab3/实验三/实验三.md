# 深度学习基础实验 3

## 一、实验目标

基于 **Enron-Spam 邮件数据集**，完成一个**垃圾邮件二分类任务**，并对以下两类模型进行系统对比：

* 基于 **Self-Attention（多头自注意力）** 的文本分类模型
* 基于 **RNN 系列（RNN / LSTM / GRU）** 的序列建模模型

## 二、数据集说明

该数据集来源于真实邮件，包含正常邮件（ham）与垃圾邮件（spam）。

数据集压缩包（enron_spam_data.zip）和加载文件（load_dataset.py）已经提供。

数据标签分布分布大致平衡，但是文本长度分布长尾明显。

## 三、实验整体流程

实验需要按照以下流程执行，并且在报告中对每一步的设计选择进行说明。

### 1. 数据划分

需要将数据划分为训练集（train）、验证集（validation）和测试集（test）。划分时必须使用分层采样（stratified split），以保证类别比例一致。同时需要注意，测试集只能用于最终评估，不参与模型调参过程。

### 2. 文本预处理

需要对原始邮件进行基础清洗，并清晰说明所采用的策略。常见的处理方式包括是否统一转为小写（通常推荐）、是否保留标点符号、是否保留邮件头信息（如 from、to、subject），以及是否去除 URL、邮箱地址、多余换行或特殊符号等。

### 3. Tokenization 与词表构建

在将文本输入模型之前，需要先将其转化为 token 序列。

可以选择基于词或字符自行构建词表的方式（推荐）。具体流程包括对文本进行分词（例如按空格切分），统计词频，并据此构建 vocabulary。在设计时需要设定最大词表大小（如 50k 或 100k），并将低频词统一映射为 `<unk>`，同时使用 `<pad>` 作为填充符。

也可以选择使用预训练 tokenizer，例如 Qwen3.5 的 tokenizer。但需要注意，在 tokenizer 之后将其输出映射到从零开始的连续整数序列。

### 4. 序列处理（Truncation 与 Padding）

由于文本长度差异较大，需要对序列进行统一处理。

首先需要进行截断（truncation），设定最大长度（max_len），具体取值应参考数据的长度分布特征。其次需要进行 padding，将所有序列使用 `<pad>` 填充到相同长度。

padding 的方向（左侧或右侧）不做强制要求，但需要在报告中说明选择理由。

### 5. Attention Mask

为了避免 padding 对模型产生干扰，需要构建 padding mask，并在 Attention 计算过程中屏蔽 `<pad>` 位置。不实现该机制，可能会对模型性能和稳定性产生不良影响。

## 四、模型设计

### 1. Self-Attention 模型

需要构建一个基于多头自注意力机制的文本分类模型。

模型应包含以下基本组件：Embedding 层用于将 token 转换为向量表示，位置编码（Positional Encoding）用于引入序列位置信息，多头自注意力模块（Multi-Head Self-Attention），以及最终的分类输出层。

在设计过程中，需要明确说明以下关键点。首先，必须引入位置编码，可以选择正弦位置编码或可学习的位置编码。其次，Attention 类型可采用双向 self-attention（即标准做法），不强制要求使用 causal mask。再次，需要说明序列表示的聚合方式，例如使用 mean pooling、max pooling、最后一个有效 token，或引入 `[CLS]` token。最后，分类输出可以采用单一输出（配合 sigmoid）或双输出（配合 softmax）两种形式。

### 2. RNN 模型

需要实现一个基于循环神经网络的模型，可以选择 RNN、LSTM 或 GRU。

模型需要包含 embedding 层，并能够正确处理变长序列。具体可以通过使用真实序列长度提取最后一个有效 hidden state，或者使用 pack/pad 机制来实现。

最终输出通常基于序列的最终 hidden state 进行分类。

## 五、训练设置

训练过程中的关键参数需要自行设计，包括损失函数（如交叉熵）、优化器（如 Adam 或 SGD）、学习率、batch size 以及训练轮数（epoch）等。

## 六、评价指标

实验结果中必须报告以下指标：Accuracy、Precision、Recall 以及 F1-score，其中 F1-score 为重点指标。

## 七、实验分析（除第一项必做之外，再任选三项完成，共计四项）

### 1. Attention 与 RNN 的比较（必做）

需要从模型性能（如 F1-score）以及计算成本（如收敛速度、显存占用和资源消耗）等方面进行对比分析。

### 2. 网络超参数的影响

可以分析 embedding 维度、attention head 数量、RNN hidden size 以及模型层数等因素对模型性能的影响。

### 3. 文本处理策略的影响

可以分析词表大小、截断长度（max_len）以及是否进行 lowercasing 等预处理策略对结果的影响。

### 4. 位置编码与 Attention 机制

可以分析是否使用位置编码的差异，不同位置编码方式（如 RoPE）的效果，以及是否使用 mask 或不同 padding 方向对模型的影响。

### 5. 序列聚合方式与分类头设计

可以比较不同聚合方式（如 mean pooling、last token、max pooling）以及不同分类输出形式（sigmoid 与 softmax）的效果差异。

### 6. Attention 可视化（推荐）

可以选取具体样本，对 attention 权重进行可视化，并分析模型关注的位置是否合理，例如是否集中在 URL、营销词或关键语义片段上。

### 7. RNN 变体比较

可以对比 RNN、LSTM 和 GRU 三种结构在该任务上的性能差异，尤其是处理不同长度的文本上。
